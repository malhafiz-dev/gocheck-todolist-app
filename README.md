# GoCheck

GoCheck is a simple TodoList app for keeping track of tasks and monitoring completion progress. It is built with React.

## Fitur

- Add items to the list.
- Mark items as complete or incomplete.
- Delete individual items or clear the entire list.
- Sort items by entry order, title, or completion status.
- View the number of completed items and overall progress percentage.

> Items are stored in memory only and will be cleared when the page is reloaded.

## Run Locally

Make sure [Node.js](https://nodejs.org/) and npm are installed, then run the following commands from the project directory:

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser. The app reloads automatically when you edit the code.

## Production Build

```bash
npm run build
```

This command creates an optimized production build in the `build/` directory.
